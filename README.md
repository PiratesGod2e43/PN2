PiratesNodes Complete Dashboard Starter
Run: npm install ; npm run dev ; open the URL printed by Next.js.

Includes Free/Paid/VPS dashboards, starter plans, custom plan creation, Owner create/give server records, member-specific server list, demo server actions, payment request view, splitter limits, and navigation for Modrinth installer, monitoring and settings.

This is a UI prototype, not a production hosting control plane. Role switcher is demo-only, data resets on refresh, server actions are simulated, and payments are not automatically charged or verified. Production needs secure server-side authentication/RBAC, database, payment provider with signed webhooks, encrypted secrets, node agents, resource enforcement, expiry scheduler, backups, audit logs and monitoring. Never publish passwords or API keys; rotate credentials previously shared in chat.
